# Computer Graphics Lab

This repository contains Python `turtle` implementations of basic Computer Graphics lab experiments.

## Experiments

1. **Two Dimensional Geometric Translation**  
   File: `translation.py`

2. **Two Dimensional Geometric Rotation**  
   File: `Rotation.py`

3. **Two Dimensional Geometric Scaling**  
   File: `Scaling.py`

4. **Bresenham Line Drawing Algorithm**  
   File: `Bresenham_line_drawing.py`

5. **DDA Algorithm**  
   File: `DDA.py`

6. **Cohen-Sutherland Line Clipping Algorithm**  
   File: `Cohen_Sutherland_Line_Clipping.py`

7. **Deterministic Self-Similar Fractal Curve (Koch Curve)**  
   File: `Koch_Curve.py`

## Basic Turtle Example

`turtle_try.py` is a simple starter program showing:

- Turtle screen setup
- Creating a Turtle object
- `penup()` and `pendown()`
- `goto()`
- Drawing X and Y axes
- Drawing a point with `dot()`
- Writing text on the screen

## Requirements

- Python 3.x
- Python Turtle module

`turtle` is included with most standard desktop Python installations.

## How to Run

Run any file from the terminal. For example:

```bash
python turtle_try.py
```

or:

```bash
python Scaling.py
```

On Linux/macOS, if needed:

```bash
python3 turtle_try.py
```
